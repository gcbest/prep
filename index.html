    Last-hour reference

    8 cheat sheets · opens on tap

    Angular change detection

    1. zone.js patches async → CD from root
    2. OnPush: skip unless input ref / template event / async pipe / signal read
    3. Signals mark views precisely — strategy-agnostic
    4. Zoneless (18+): signals/AsyncPipe/markForCheck drive updates

    Template method calls re-run every cycle — pipe or computed() them.

    Signals & control flow

    • signal() · computed() · effect() · toSignal()
    • @if / @else · @for (… track id) · @empty
    • @defer + @placeholder/@loading/@error
    • input() / output() — decorator-free APIs

    switchMap cancels; exhaustMap guards submits.

    Event loop order

    1. Run current macrotask
    2. Drain all microtasks
    3. rAF → style → layout → paint
    4. Next macrotask…

    Specificity scale

    1. style="" inline
    2. #id
    3. .class / [attr] / :hover
    4. element / ::before

    @layer: later layers win; unlayered beats layered.

    Vitals thresholds

    LCP< 2.5s
    INP< 200ms
    CLS< 0.1
    TTFB< 800ms

    Field data, 75th percentile — not lab Lighthouse.

    HTTP status drill

    301 / 302permanent / temporary
    304not modified (cache)
    401 / 403who? / not allowed
    422semantically invalid
    429too many requests

    Cache headers

    • Cache-Control: max-age=31536000, immutable — hashed assets
    • no-cache — revalidate: ETag / If-None-Match → 304
    • stale-while-revalidate — serve stale, refresh after
    • Vary — key the cache correctly

    Whiteboard openers

    • Restate the problem. Name users & scale.
    • Clarify: data size, latency budget, a11y scope.
    • Draw states first (empty/loading/error/data).
    • Name the a11y pattern before the pixels.

    Glossary — the words your stakeholders will use

    IBANInternational account number. Mod-97 checksum — pre-validate it client-side and you'll look senior.
    SWIFT / BICBank identifier codes for cross-border messaging between institutions.
    ACH · FedNowU.S. batch payments vs instant payments rails — different latency promises in the UI.
    ISO 20022Rich-data payments messaging standard replacing sparse legacy formats (incl. legacy SWIFT MT).
    KYC / AMLKnow-your-customer identity checks + anti-money-laundering screening — onboarding flows must model these states.
    OFAC screeningSanctions checks on parties; expect “pending screening”/hold states in payment UIs.
    Maker-checkerDual authorization — one person creates a payment, another approves. UI must model the four-eyes lifecycle.
    Nostro / vostroCorrespondent bank accounts each side of a border; reconciliation views built on them.
    T+1Trade settles one business day after execution (U.S. equities since May 2024).
