02

React → Angular

transfer your React muscle memory

If the panel asks “you've been a React shop — how fast do you come up to speed on Angular?”, this section is your answer. React taught you composition, lifted state, controlled inputs, cancellation, memoization and test discipline. Angular renames almost all of it — and adds two things React leaves to the ecosystem: dependency injection and a router with guards built in. Below: the crib sheet, then one real feature — a limit-breach monitor, the kind of screen ERT ships — written both ways, then the traps that catch React developers in code review.

The mental shift

  • UI = f(state) still holds. React re-runs the function and diffs the result; Angular diffs the template against its last value — you rarely re-render, you update a value.
  • State lives in signals. signal() is useState with a getter; computed() is useMemo without a dependency array, because reads are tracked for you.
  • Immutability still matters. With OnPush — Angular's React.memo — mutating an array in place means a silent no-update. Same bug, new framework.
  • Hooks rules → injection-context rules. You may not call useState inside a condition; you may not call inject() outside a constructor, field initializer or factory.
  • Effects are not the same effect. React's useEffect runs after paint on every dependency change; Angular's effect() runs after change detection and re-runs only when the signals it read change.
  • Composition maps one-to-one. Props → input(), children → <ng-content>, callbacks → output(), custom hooks → services or directives.

Panel line: “I'd keep the React mental model — derived state, cancellation, stable keys — and re-express it as signals, OnPush and switchMap.”

Worked example · limit-breach monitor

ReactBreachMonitor.jsx
import { useEffect, useMemo, useState } from "react";
import { fetchBreaches } from "./api";

export function BreachMonitor({ deskId, onOpen }) {
  const [query, setQuery] = useState("");
  const [attempt, setAttempt] = useState(0);
  const [rows, setRows] = useState([]);
  const [status, setStatus] = useState("loading");

  useEffect(() => {
    const ctrl = new AbortController();     // cancellation
    setStatus("loading");
    fetchBreaches(deskId, query, { signal: ctrl.signal })
      .then((data) => { setRows(data); setStatus("ready"); })
      .catch((e) => e.name !== "AbortError" && setStatus("error"));
    return () => ctrl.abort();              // cleanup
  }, [deskId, query, attempt]);

  const sorted = useMemo(                   // derived state
    () => [...rows].sort((a, b) => b.util - a.util),
    [rows]
  );

  if (status === "loading") return <Spinner />;
  if (status === "error")
    return <ErrorState onRetry={() => setAttempt((a) => a + 1)} />;

  return (
    <table>
      <tbody>
        {sorted.map((r) => (
          <tr key={r.id} onClick={() => onOpen(r.id)}>
            <td>{r.limitName}</td>
            <td>{r.util}%</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
Angularbreach-monitor.component.ts
@Component({
  selector: "app-breach-monitor",
  imports: [DecimalPipe],
  templateUrl: "./breach-monitor.component.html",
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class BreachMonitor {
  deskId = input.required<string>();   // props → input()
  open   = output<string>();           // onOpen → output()

  query   = signal("");                // useState → signal()
  attempt = signal(0);
  rows    = signal<Breach[]>([]);
  status  = signal<"loading" | "ready" | "error">("loading");

  sorted = computed(() =>              // useMemo — deps tracked
    [...this.rows()].sort((a, b) => b.util - a.util)
  );

  private api = inject(BreachApi);     // context → DI

  constructor() {
    toObservable(computed(() => ({ desk: this.deskId(),
                                   q: this.query(),
                                   n: this.attempt() })))
      .pipe(
        debounceTime(300),
        distinctUntilChanged((a, b) => a.desk === b.desk &&
                                       a.q === b.q && a.n === b.n),
        tap(() => this.status.set("loading")),
        // switchMap cancels the in-flight call — this IS AbortController
        switchMap(({ desk, q }) =>
          this.api.breaches(desk, q).pipe(
            map((rows) => ({ ok: true, rows })),
            catchError(() => of({ ok: false, rows: [] }))
          )
        ),
        takeUntilDestroyed()           // the cleanup function
      )
      .subscribe(({ ok, rows }) => {
        this.rows.set(rows);
        this.status.set(ok ? "ready" : "error");
      });
  }

  retry() { this.attempt.update((n) => n + 1); }
}
Angularbreach-monitor.component.html
@if (status() === "loading") {
  <app-spinner />
} @else if (status() === "error") {
  <app-error-state (retry)="retry()" />
} @else {
  <table>
    <caption>Limit breaches — {{ deskId() }}</caption>
    <tbody>
      @for (r of sorted(); track r.id) {
        <tr (click)="open.emit(r.id)">
          <td>{{ r.limitName }}</td>
          <td>{{ r.util }}%</td>
        </tr>
      } @empty {
        <tr><td colspan="2">No breaches for this desk.</td></tr>
      }
    </tbody>
  </table>
}

Read it as a translation, not a rewrite: useState → signal, useMemo → computed, dependency array → signal reads, AbortController → switchMap, cleanup → takeUntilDestroyed, key → track, early returns → @if / @else. The file count grows (class, template, spec); the logic does not. Notice what disappeared: hand-rolled spinner state, the fetch call on the render path, and the memo comparison you had to reason about.

Rendering 500 breaches: memo → OnPush

  • React.memo → OnPush, on every component. The strategy is per component, so set it once in the CLI defaults and never think about it again.
  • Pass data, don't mutate it. An input must receive a new reference to change: this.rows.set(rows), .map(), spread — the React rule, verbatim.
  • key → track. Track the breach id. track $index rebuilds rows on sort — you'll see it as flicker and lost focus.
  • Heavy widgets: @defer (on viewport) for the chart panel; CDK virtual scroll for 10k rows instead of react-window.
  • Derived values: computed() on the class, never a method in the template — a method call re-evaluates on every change-detection pass.
  • CSS: component styles are encapsulated by default; :host ≈ a styled-component's root, and Bootstrap still leaks in like a global stylesheet.

Profile in Angular DevTools: if the flame graph doesn't move when you type, your state never changed reference.

@Injectable({ providedIn: "root" })

    return this.http.get<Breach[]>("/api/limits/breaches",

}

Business or data logic → service. DOM behaviour → directive: your useDebouncedClick becomes <button appDebounceClick> with @HostListener — and @if, @for, ngClass, ngStyle are directives you were hand-rolling as hooks.

Gotchas, the conversion checklist, and an honest scorecard

Where React devs get burned (week 1)

  1. Missing (). {{ rows }} prints a function or a stale object. Signals are called.
  2. Mutating, then expecting a repaint. OnPush + push() in place = nothing happens. New array, new ref.
  3. Method calls in the template. {{ total() }} is cheap; {{ computeTotal() }} runs on every change-detection pass. Make it a computed().
  4. Observables without cleanup. http.get().subscribe() inside a component outlives navigation until you add takeUntilDestroyed().
  5. Cold observables. The same http.get() subscribed twice = two HTTP calls. Put the request in one place: a service method or one effect.
  6. (input) vs (change). One fires per keystroke, one on blur — the React onChange subtlety, relocated.
  7. Forgetting OnPush on a new component. Default change detection hides your stale-render bugs until production.
  8. Styles. Your component CSS stops at the component boundary; Bootstrap keeps leaking in. Audit class names the way you audited CSS modules.

Convert a React file in ten moves

  1. ng g c breach-monitor --standalone --change-detection OnPush.
  2. Paste the JSX return into .html: className → class, {x} → {{ x() }}, handlers → (evt)="…", expressions → [prop]="…".
  3. Each useState → a signal() field with the same initial value; setX → x.set() / x.update().
  4. useMemo → computed(). Data useRef → another signal. DOM ref → viewChild().
  5. Classify every useEffect: one-shot init → ngOnInit; signal-driven side effect → effect(); async with deps → a stream in the constructor closed by takeUntilDestroyed().
  6. Props → input() / input.required(); callbacks → output(); children → <ng-content>; default props → the input's default value.
  7. Context/Redux → a providedIn: 'root' service; every useContext(X) becomes a private x = inject(X) field.
  8. Move fetch/WebSocket code into an injectable service so HttpTestingController can see it.
  9. key → track (stable id), React.memo → OnPush, Suspense → @defer.
  10. Port the test: RTL queries → By.css/By.role, waitFor → whenStable() or fakeAsync/tick(); then run Karma and Cypress.

Honest scorecard — say it out loud

React winsEcosystem breadth, hiring pool, server components, the smallest possible mental model for one screen.
Angular winsDI, typed forms, guards & resolvers, structure that survives a 40-person team, template type-checking, RxJS cancellation, CDK a11y primitives.
In a regulated bankRouter, forms and the test runner ship in the framework — fewer third-party libraries to license, audit and patch.
Micro frontendsModule Federation is first-party in both; Angular's build enforces the boundaries ERT's team split needs.

“With React I'd hand-pick a router, a form library, a state library and a fetch layer — four separate supply-chain and upgrade decisions. For a risk platform I'd take Angular's opinionated defaults.”

    • Long-running tagline: “The Citi never sleeps.”

    Milestones worth quoting

    1. 1812June 16 — City Bank of New York founded; first president Samuel Osgood. Depository status won financing the War of 1812.
    2. 1967The “Everything Card” — First National City's charge card, an early consumer credit revolution.
    3. 1976Renamed Citibank, N.A. (from First National City Bank); “Citibank” had been the wire-code nickname since the 1860s.
    4. 1977One of the first ATMs — 24-hour service launched in Queens, pivoting the bank to retail.
    5. 1981Cards move to Sioux Falls, SD — the interest-rate arbitrage that made Sioux Falls a card capital.
    6. 1998Citicorp + Travelers merger — record ~$70B deal creates Citigroup; Paula Scher's arc logo arrives with it.
    7. 2007Umbrella sold back to Travelers; Citi keeps the arc. Financial crisis support follows a year later.
    8. 2012Bicentennial — 200 years. Citi Bike follows in 2013.
    9. 2016HQ returns to 388 Greenwich Street, lower Manhattan.
    10. 2021Jane Fraser becomes CEO (Mar 1) — the first woman to lead a major U.S. bank.
    11. 2023Org simplified to five businesses, each led by a direct report to the CEO.
    12. 2025$85.2B revenue — decade high; Fraser named Chair (Oct); CFO transition + USPB reorg announced (Nov); OCC removes 2024 amendment (Dec).
    13. 2026Luchetti takes CFO (Mar); FY2025 10-K filed — five segments incl. U.S. Consumer Cards; Russia exit closed (Feb); revised Basel III Endgame proposals (Mar).

    T+1Trade settles one business day after execution (U.S. equities since May 2024).
